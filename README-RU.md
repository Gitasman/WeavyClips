# Weavy Clips v2.2.1

## Как обновить

1. В прежней версии сделайте Backup → Export JSON.
2. Замените файлы в **той же папке**, из которой расширение загружено в Chrome. В этой версии нужны также ui.js и ui.css.
3. На chrome://extensions нажмите обновление расширения. Для штатной боковой панели добавлено разрешение sidePanel.
4. Один раз обновите вкладки Weavy и заново откройте настройки через значок расширения или шестерёнку дока.

Не удаляйте прежнее расширение: так сохранится его ID и локальные клипы. Установка из новой папки может создать другой ID.

Требуется Chrome 116 или новее. Сборка, npm и Node для установки расширения не нужны.

## Верхняя панель настроек

Название, поиск и навигация закреплены сверху на полностью непрозрачной подложке цвета секций. Подложка следует теме Settings Page. Переход к разделу учитывает фактическую высоту панели, чтобы заголовок не оказался под ней.

## Оформление

- Цветной эмодзи Save **💾** возвращён. Значки центрируются в отдельной области внутри кнопок, с оптическим смещением вверх на 1 px.
- Live preview использует фон и точки страницы настроек, с общей фазой узора, как вырез в карточке. Отдельного декоративного фона больше нет.
- Shadow strength отвечает за насыщенность тени; **Shadow softness** — размытость; **Shadow direction** — угол; **Shadow distance** — смещение.
- Направление тени: 0° вправо, 90° вниз, 180° влево, 270° вверх.
- Outline thickness, color, opacity задают обводку. Толщина 0 полностью её убирает.
- Нулевая сила тени отключает тень независимо от других параметров.
- Прозрачность по-прежнему затрагивает только фон. При 100% непрозрачности blur скрыт — это соответствует скриншоту. Для стеклянного эффекта выберите Glass.

## Пресеты

Встроены **Default, Glass, Solid, Compact**. Каждый хранит оформление дока и страницы настроек вместе, без клипов, положения, методов вставки и автоскрытия.

- Выбор пресета сразу применяет его; **Apply** повторно применяет выбранный пресет после ручных изменений.
- Введите имя и нажмите **Save new**, чтобы сохранить текущую тему.
- Для своего выбранного пресета **Update** сохраняет текущие значения и имя.
- **Delete** удаляет выбранный пользовательский пресет после подтверждения; текущая тема остаётся.
- Встроенные пресеты защищены от изменения и удаления. Свою вариацию сохраните через Save new.
- Пользовательские пресеты входят в Backup JSON и восстанавливаются при импорте. Совпадающие ID при импорте не дублируются.

## Интерфейс и работа с клипами

- Настройки открываются в штатной **боковой панели Chrome**, рядом с сайтом. Сторону (справа или слева) определяет настройка самого Chrome; расширение не меняет её. Пункт Options в системном меню Chrome по-прежнему позволяет открыть полную страницу.
- Порядок: Appearance → Settings Page → Clips Manager → Backup → Default Dock Position → Dock Behavior → Site Settings → Clipboard & Paste → Diagnostics.
- Разделы сворачиваются нажатием на заголовок; состояние сохраняется. Вверху есть короткая навигация.
- **Alt+K** открывает быстрый поиск клипов. В Weavy: Enter вставляет выбранный клип текущим методом. В настройках: Enter копирует его в буфер. Стрелки выбирают, Escape закрывает. Есть и кнопка Search.
- Док можно перемещать за точки и за свободную область между/вокруг кнопок. Нажатия кнопок и перетаскивание клипов сохраняют свои действия.
- Перестановка клипов и открытие Library получили короткие анимации 140–150 мс с поддержкой системного уменьшения движения.
- Clips Manager и Library используют виртуализацию: создаются только видимые карточки и небольшой запас. Поиск охватывает весь список.
- Превью сохранённых клипов-картинок получают источник изображения при приближении к видимой области. Это экономит декодирование и отрисовку, но само хранилище клипов по-прежнему читается целиком.
- В Dock Behavior есть необязательный **Auto-hide dock when idle**: через 1,1 с остаётся узкая область с точками в сохранённом месте; наведение раскрывает док. По умолчанию выключен.

## Проверки

45 проверок логики и 29 интеграционных проверок DOM проходят: значения со скриншота, нули, быстрая запись, устаревшие события, ошибка/повтор сохранения, отдельные параметры тени/обводки, пресеты и параллельные операции, порядок разделов, виртуализация и поиск по 1 200 клипам, перетаскивание за фон, отложенная установка источника изображения, обработчик боковой панели.

- `node tests/regression.cjs` — без дополнительных зависимостей.
- `npm install` и `npm test` — также проверяет интерфейс через LinkeDOM. Зависимости нужны только для тестов.

Проверки выполняют реальный JS расширения с имитацией Chrome API. Они **не заменяют** проверку установленного расширения в Chrome: пиксельное выравнивание эмодзи, визуальная анимация, разрешение открытия side panel по пользовательскому жесту и вставка в живой Weavy здесь не проверены.
