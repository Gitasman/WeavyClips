# Weavy Clips v2.5.1

[English](README.md) · **Русский**

Основная документация репозитория — на английском. Эта страница — русский перевод. Встроенная справка Help выбирает EN/RU по языку браузера и позволяет переключить язык вручную. Интерфейс настроек остаётся английским.

## Новое в 2.5.1

- Все девять разделов находятся на одной странице и раскрыты по умолчанию, включая блоки пресетов, истории и восстановления.
- Верхняя навигация прокручивает к нужному разделу с учётом высоты закреплённой панели; текущий пункт подсвечивается при ручной прокрутке.
- Уплотнены отступы, поля, пресеты и карточки бэкапа. На широком экране позиция дока и её preview стоят рядом, способы копирования/вставки — в двух колонках.
- Строки клипов и диагностика подготавливаются при приближении к разделу. Высота списка резервируется заранее, обработка прокрутки объединена в один кадр, параллельные запросы диагностики объединяются.

## Новое в 2.5.0

- Настройки разделены на девять самостоятельных экранов. Активный раздел выделяется и запоминается; стрелки и Home/End переключают вкладки.
- Appearance сгруппирован по форме/цвету, прозрачности/блюру, тени и обводке. Live preview поднят наверх и следует за прокруткой, сохраняя фон страницы.
- Импорт и экспорт получили отдельные карточки. Восстановление и очистка находятся в раскрываемом блоке, параметры истории — рядом с Clips Manager.
- Library использует симметричную SVG-иконку. Центровка эмодзи вычисляется по метрикам установленного шрифта, цветная дискета сохранена. Док и preview используют общие правила.
- Скрытый Clips Manager не создаёт строки заранее; диагностика запрашивается при открытии раздела. Удалены дубли стилей кнопок, CSS настроек переработан для широкого и узкого окна.

## Новое в 2.4.1

- Исправлены слои: меню и подсказки отображаются выше дока и Library.
- В Library две отдельные кнопки 📥 Import и 📤 Export; промежуточное меню убрано.
- Компактные строки показывают иконку, название, дату обновления и действия. Превью содержимого, тип, миниатюры и счётчики убраны из списка.
- Clips Manager тоже уплотнён; группа редактируется по кнопке 🏷️.
- Уменьшены отступы и высота контролов настроек; навигация разделов занимает одну прокручиваемую строку.
- Форматирование дат использует общий кешируемый форматтер. Содержимое клипов сохранено в хранилище, поиске и экспорте.

## Новое в 2.4.0

- Backup — первый раздел. Здесь находятся импорт, экспорт, Apply bundled defaults и выбор открытия настроек.
- По умолчанию настройки открываются в новой вкладке. В Backup → Open settings in можно выбрать Chrome side panel; настройку используют и шестерёнка, и значок расширения.
- Квадратная кнопка ⇅ в заголовке Library открывает экспорт и импорт JSON.
- Подсказка клипа содержит только название и дату обновления. Контекстное меню использует фон, акцент, контрастный текст, радиус, обводку и тень из Appearance.
- Lock и Pin убраны из меню по правому клику, но остаются в Library и Clips Manager.
- Новые дефолты: непрозрачность дока 0%, blur 5 px, сила тени 85%, мягкость 18 px, непрозрачность обводки 6%. Всплывающие поверхности остаются непрозрачными для читаемости.

Публичная сборка включает настройки без личных клипов. Личная сборка может содержать стартовую библиотеку в default-backup.json. Она применяется один раз при новой установке. Для существующей установки используйте Backup → Apply bundled defaults: настройки применятся, недостающие клипы добавятся, существующие сохранятся. Сохранённые абсолютные координаты экрана не становятся общим дефолтом — используется относительная позиция дока.

## Новое в 2.3.0

- Последовательная запись изменений клипов через service worker: разные вкладки сохраняют добавления и изменения разных полей. Для одновременных правок одного поля действует последнее обработанное значение.
- В сообщениях передаются изменённые поля вместо всей библиотеки. Само локальное хранилище по-прежнему читает и записывает библиотеку целиком.
- Док сохраняет кнопки при обновлении статистики; активное поле редактирования не исчезает при фоновых обновлениях. Escape отменяет переименование, даже если затем срабатывает blur.
- Поиск использует общий кеш: несколько слов, диакритика, имена, группы, типы и первые 2000 символов текста/JSON. Содержимое картинок не индексируется.
- Фильтры All, Pinned, Images, Text, JSON и счётчик результатов в Clips Manager. После удаления доступна Undo.
- При ошибке сохранения клипов появляется Retry. Несохранённые изменения остаются в открытой странице: не закрывайте её до успешного сохранения.
- Импорт проверяет версию, ID, типы и историю до добавления клипов. Лимит файла — 64 МБ, до 50 000 клипов; неизвестные ключи настроек игнорируются.
- Новые файлы `clips.js` и `help.*` обязательно копируются при обновлении. Обновите все вкладки Weavy после перезагрузки расширения.

## Установка

1. [Скачайте ZIP](https://github.com/Gitasman/WeavyClips/archive/refs/heads/main.zip), распакуйте в постоянную папку.
2. В `chrome://extensions` включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение» и выберите папку с `manifest.json`.
4. Откройте или обновите app.weavy.ai. Для установки npm и сборка не нужны.


## Как обновить

1. В прежней версии сделайте Backup → Export JSON.
2. Замените файлы в **той же папке**, из которой расширение загружено в Chrome. Нужны все исполняемые файлы, включая clips.js, ui.js, ui.css и help.*.
3. На chrome://extensions нажмите обновление расширения. Для штатной боковой панели добавлено разрешение sidePanel.
4. Один раз обновите вкладки Weavy и заново откройте настройки через значок расширения или шестерёнку дока.

Не удаляйте прежнее расширение: так сохранится его ID и локальные клипы. Установка из новой папки может создать другой ID.

Требуется Chrome 116 или новее. Сборка, npm и Node для установки расширения не нужны.

## Верхняя панель настроек

Название, поиск и навигация закреплены сверху на полностью непрозрачной подложке цвета секций. Подложка следует теме Settings Page. Переход к разделу учитывает фактическую высоту панели, чтобы заголовок не оказался под ней.

## Оформление

[DESIGN.md](DESIGN.md) описывает визуальный стиль и принципы Appearance для других расширений.

- Цветной эмодзи Save **💾** возвращён. Значки центрируются в отдельной области внутри кнопок, с поправкой по фактическим метрикам шрифта операционной системы вместо фиксированного смещения.
- Live preview использует фон и точки страницы настроек, с общей фазой узора, как вырез в карточке. Отдельного декоративного фона больше нет.
- Shadow strength отвечает за насыщенность тени; **Shadow softness** — размытость; **Shadow direction** — угол; **Shadow distance** — смещение.
- Направление тени: 0° вправо, 90° вниз, 180° влево, 270° вверх.
- Outline thickness, color, opacity задают обводку. Толщина 0 полностью её убирает.
- Нулевая сила тени отключает тень независимо от других параметров.
- Прозрачность по-прежнему затрагивает только фон. При 100% непрозрачности blur скрыт. Для стеклянного эффекта выберите Glass.

## Пресеты

Встроены **Default, Glass, Solid, Compact**. Каждый хранит оформление дока и страницы настроек вместе, без клипов, положения, методов вставки и автоскрытия.

- Выбор пресета сразу применяет его; **Apply** повторно применяет выбранный пресет после ручных изменений.
- Откройте **Manage my presets**, введите имя и нажмите **Save new**, чтобы сохранить текущую тему.
- Для своего выбранного пресета **Update** сохраняет текущие значения и имя.
- **Delete** удаляет выбранный пользовательский пресет после подтверждения; текущая тема остаётся.
- Встроенные пресеты защищены от изменения и удаления. Свою вариацию сохраните через Save new.
- Пользовательские пресеты входят в Backup JSON и восстанавливаются при импорте. Совпадающие ID при импорте не дублируются.

## Интерфейс и работа с клипами

- Настройки по умолчанию открываются **в новой вкладке**. Для открытия рядом с сайтом выберите Chrome side panel в первом разделе Backup. Сторону (справа или слева) определяет настройка самого Chrome; расширение не меняет её. Пункт Options в системном меню Chrome по-прежнему позволяет открыть полную страницу.
- Порядок: Backup → Appearance → Settings Page → Clips Manager → Dock Position → Dock Behavior → Site Settings → Clipboard & Paste → Diagnostics.
- Все разделы открыты на общей странице. Навигация закреплена сверху и прокручивает к нужному разделу; стрелки и Home/End также работают. Текущий пункт подсвечивается при прокрутке.
- **Alt+K** открывает быстрый поиск клипов. В Weavy: Enter вставляет выбранный клип текущим методом. В настройках: Enter копирует его в буфер. Стрелки выбирают, Escape закрывает. Есть и кнопка Search.
- Док можно перемещать за точки и за свободную область между/вокруг кнопок. Нажатия кнопок и перетаскивание клипов сохраняют свои действия.
- Перестановка клипов и открытие Library получили короткие анимации 140–150 мс с поддержкой системного уменьшения движения.
- Clips Manager и Library используют виртуализацию: создаются только видимые карточки и небольшой запас. Поиск охватывает весь список.
- Строки списка не показывают и не декодируют изображения. Содержимое клипов сохраняется; хранилище по-прежнему читается целиком.
- В Dock Behavior есть необязательный **Auto-hide dock when idle**: через 1,1 с остаётся узкая область с точками в сохранённом месте; наведение раскрывает док. По умолчанию выключен.

## Проверки

Набор проверок покрывает: значения со скриншота, нули, быстрая запись, устаревшие события, ошибка/повтор сохранения, отдельные параметры тени/обводки, пресеты и параллельные операции, порядок разделов, виртуализация и поиск по 1 200 клипам, перетаскивание за фон, отложенная установка источника изображения, обработчик боковой панели.

- `node tests/regression.cjs` — без дополнительных зависимостей.
- `npm ci --ignore-scripts` и `npm test` — также проверяет интерфейс через LinkeDOM. Зависимости нужны только для тестов.

Проверки выполняют реальный JS расширения с имитацией Chrome API. Они **не заменяют** проверку установленного расширения в Chrome: пиксельное выравнивание эмодзи, визуальная анимация, разрешение открытия side panel по пользовательскому жесту и вставка в живой Weavy здесь не проверены.
