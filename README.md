# Weavy Clips

**Версия 2.2.1 · расширение для Chrome 116+ · для app.weavy.ai**

Сохраняйте содержимое буфера обмена и фрагменты Weavy в клипы, чтобы повторно вставлять их из плавающего дока.

- Библиотека клипов, поиск `Alt+K`, закрепление и история версий клипа.
- Настраиваемый док: цвета, размер, прозрачность, blur, тень, обводка и пресеты.
- Настройки в боковой панели Chrome, отдельное оформление страницы настроек.
- Экспорт и импорт клипов, настроек и пользовательских пресетов через JSON.

## Скачать и установить

1. **[Скачайте ZIP с исходниками](https://github.com/Gitasman/WeavyClips/archive/refs/heads/main.zip)** и распакуйте его в постоянную папку. Не удаляйте эту папку после установки.
2. Откройте `chrome://extensions` в Chrome.
3. Включите **Режим разработчика / Developer mode**.
4. Нажмите **Загрузить распакованное расширение / Load unpacked** и выберите папку, в которой находится `manifest.json`. В архиве GitHub это папка `WeavyClips-main`.
5. Откройте или обновите [app.weavy.ai](https://app.weavy.ai/). Для настроек нажмите значок расширения или шестерёнку на доке.

Установка из исходников: Node.js, npm и сборка не нужны. Этот репозиторий не устанавливает расширение из Chrome Web Store.

## Обновить и сохранить свои клипы

1. В настройках расширения сделайте **Backup → Export JSON**.
2. Скачайте свежий ZIP и распакуйте его отдельно.
3. Скопируйте новые файлы **в ту же постоянную папку**, из которой Chrome уже загрузил расширение, с заменой существующих файлов.
4. В `chrome://extensions` нажмите кнопку обновления Weavy Clips, затем обновите вкладки Weavy и заново откройте настройки.

Не удаляйте расширение и не загружайте новую папку вместо старой: другой путь может изменить ID расширения и создать отдельное локальное хранилище. Обновление из GitHub выполняется вручную.

## Данные и разрешения

Клипы и настройки хранятся в `chrome.storage.local` в профиле браузера. Синхронизации через GitHub нет. JSON из Backup содержит сами клипы: храните его у себя и не добавляйте в публичный репозиторий.

| Разрешение | Для чего используется |
| --- | --- |
| Доступ к `app.weavy.ai` | Плавающий док и работа с клипами на страницах Weavy |
| `clipboardRead`, `clipboardWrite` | Чтение и запись буфера обмена при сохранении и вставке |
| `storage`, `unlimitedStorage` | Локальная библиотека, включая клипы с изображениями |
| `tabs` | Поиск вкладок Weavy и обмен сообщениями с ними |
| `debugger` | Эмуляция системного копирования/вставки для соответствующих методов в Clipboard & Paste |
| `sidePanel` | Настройки рядом с открытой страницей |

Подробности оформления, пресетов и режимов работы: **[README-RU.md](README-RU.md)**.

## Как пользоваться этим репозиторием

- **Code** — актуальные файлы проекта. `main` — основная ветка.
- **Commits** — история сохранённых изменений: что, когда и зачем поменялось.
- **Issues** — ошибки и идеи. Для ошибки укажите версию, шаги повторения и ожидаемый результат; не прикладывайте личные клипы без необходимости.
- **Pull requests** — предлагаемые изменения, которые можно проверить до включения в `main`.

Чтобы поделиться расширением, отправьте ссылку на [этот репозиторий](https://github.com/Gitasman/WeavyClips) или ссылку на ZIP выше. Получателю достаточно выполнить раздел «Скачать и установить».

Для следующего обновления можно попросить помощника изменить код в этом репозитории. Изменения проверяются, получают коммит и попадают в `main`; скачивание ZIP после этого содержит новую версию. Обновляйте номера в `manifest.json` и `package.json` вместе, когда выпускаете следующую версию расширения.

## Для разработки

Исходники написаны на JavaScript, HTML и CSS. Исполняемые файлы находятся в корне, сборки нет.

```sh
npm ci
npm test
```

Node.js и npm нужны только для проверок. `npm ci` устанавливает тестовые зависимости по `package-lock.json`; сценарии установки зависимостей не нужны. Без установки зависимостей можно выполнить только проверки логики:

```sh
node tests/regression.cjs
```

Тесты запускают JS расширения с имитацией Chrome API; DOM-проверки используют LinkeDOM. Они не заменяют проверку установленного расширения в Chrome и вставки в живой Weavy.

| Файл | Назначение |
| --- | --- |
| `manifest.json` | Версия, разрешения и точки входа Chrome |
| `background.js` | Service worker, запись настроек, системное копирование/вставка |
| `content.js`, `content.css` | Док и библиотека на сайте Weavy |
| `options.html`, `options.js`, `options.css` | Настройки и менеджер клипов |
| `appearance.js`, `appearance.css` | Общая модель оформления дока и live preview |
| `ui.js`, `ui.css` | Поиск, виртуализация и общие элементы интерфейса |
| `tests/` | Проверки логики и DOM |

Перед публикацией следующего изменения выполните тесты и проверьте нужный сценарий в Chrome. Пароли, ключи, локальные backup-файлы и `node_modules` в репозиторий не добавляются.
